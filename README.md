# Snupk Homebrew tap

```sh
brew tap snupk/tap && brew trust snupk/tap && brew install --cask exhausted-model
```

| Cask | App |
|---|---|
| `exhausted-model` | [Exhausted Model](https://github.com/Snupk/exhausted-model): menu bar tracker for Claude Code usage |

Homebrew 7+ only loads casks from taps you trust, hence `brew trust`.
